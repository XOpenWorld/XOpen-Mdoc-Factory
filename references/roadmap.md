## 2. 优先级矩阵

<!-- 价值 vs 难度四象限 -->

```
            高价值
              │
   ┌──────────┼──────────┐
   │  P1:快速 │  P0:核心 │
   │  胜出    │  必做    │
低 ├──────────┼──────────┤ 高
难 │  P2:观望 │  P1:计划 │
度 │          │  投入    │
   └──────────┼──────────┘
              │
            低价值
```

### 优先级说明

| 优先级 | 定义 | 决策规则 |
|--------|------|----------|
| **P0** | 必须做 | 缺少则产品无法上线 |
| **P1** | 应该做 | 显著提升用户体验或竞争力 |
| **P2** | 可以做 | 锦上添花，资源允许时做 |
