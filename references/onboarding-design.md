## 2. 首次启动流程

### 2.1 注册 → 首次进入产品

```
[落地页/下载页]
        ↓
[注册页] Email + Password（或 Google/GitHub 一键登录）
        ↓
[邮件验证]（可选，发送验证邮件）
        ↓
[欢迎页 / 用户调研]（可选，3 个问题了解使用场景）
        ↓
[引导式 Setup]（可选，根据问卷定制）
        ↓
[产品主界面 + 引导覆盖层]
        ↓
[第一个核心动作：创建/导入第一份文档]
```

### 2.2 欢迎页（可选，推荐）

展示内容：
1. 欢迎语 + 用户名
2. 1–3 个快速问题（了解使用场景，用于个性化）

示例问题：
- "你主要用来做什么？" — 写作 / 笔记 / 文档协作 / 代码文档
- "你从哪里了解到我们？" — 朋友推荐 / 搜索 / 社交媒体 / ...
- "你之前用什么工具？" — Typora / Obsidian / Notion / 其他

## 4. 引导覆盖层（Guided Tour）

在用户第一次进入主界面时触发。

### 步骤设计

| 步骤 | 高亮区域 | 提示文案 | 按钮 |
|------|---------|---------|------|
| 1/5 | 侧边栏 | 这里是你的文档库，可以创建文件夹来整理文档 | 下一步 |
| 2/5 | 新建按钮 | 点击这里创建你的第一篇文档 | 下一步 |
| 3/5 | 编辑器 | 左侧是 Markdown 编辑器，右侧实时预览 | 下一步 |
| 4/5 | 格式工具栏 | 使用工具栏快速插入标题、链接等格式 | 下一步 |
| 5/5 | 分享按钮 | 一键生成分享链接，随时分享给他人 | 完成 |

### 引导层规范

- 遮罩：半透明黑色背景 `rgba(0,0,0,0.6)`
- 高亮：目标元素 `box-shadow: 0 0 0 9999px rgba(0,0,0,0.6)`
- 提示卡片：白色圆角卡片，靠近高亮元素
- 进度：右上角显示 `1/5` 步骤数
- 跳过：右上角「跳过引导」链接
- 用户可随时通过 「帮助 → 重新引导」 重放

## 5. 功能发现机制

### 5.1 渐进式功能曝光

| 行为触发 | 曝光功能 |
|---------|---------|
| 编辑 3 分钟后 | 提示「试试 Ctrl+S 保存，或开启自动保存」 |
| 创建第 3 篇文档 | 提示「文档多了？试试创建文件夹来整理」 |
| 粘贴长文本后 | 提示「试试 AI 摘要，快速提炼关键信息」 |
| 分屏模式切换 | 提示「你可以拖动分隔线调整编辑/预览比例」 |

### 5.2 Feature Callout（功能气泡）

新功能上线时，在相关按钮旁显示蓝色圆点 + 气泡提示：
- 气泡显示 3 天
- 用户点击后不再显示
- 每次最多同时显示 1 个 Callout

## 7. 帮助系统

### 7.1 帮助入口

- 工具栏右下角「?」按钮
- 快捷键 `F1` 打开帮助中心
- 输入框中输入 `?` 或 `/help` 触发（可选）

### 7.2 帮助内容

- 快捷键速查（Ctrl+/ 打开）
- Markdown 语法速查
- 常见问题（FAQ）
- 视频教程入口
- 联系支持

### 7.3 上下文帮助

- 表单输入错误时：提示具体错误原因
- 网络离线时：提示「当前离线，自动保存到本地」
- 存储即将用完：提示「存储已使用 90%，考虑升级 Pro」

## 8. 激活指标与漏斗

```
注册         ────── 100%
            ↓
填写欢迎信息  ────── 目标 90%
            ↓
进入主界面   ────── 目标 88%
            ↓
完成引导    ────── 目标 70%（或跳过）
            ↓
创建第 1 篇文档 ── 目标 60%（Activation）
            ↓
第 7 日回访  ────── 目标 40%（Retention D7）
```

**关键激活事件（Aha Moment）**：
> 用户在 10 分钟内**完成第一篇文档并看到实时预览**，则留存率显著提升。
